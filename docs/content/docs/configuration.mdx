# Configuration

The root `.env.example` file documents the supported settings for configuring Arbiter.

Copy the example file to `.env` to override the defaults.

```bash
cp .env.example .env
```

## Example `.env`

```bash
# Server bindings
ARBITER_HOST=127.0.0.1
ARBITER_PORT=8765
ARBITER_TRUSTED_HOSTS=localhost,127.0.0.1,::1
ALLOW_REMOTE_ACCESS=false
ARBITER_STATE_DIRECTORY=~/.local/state/arbiter

# Data persistence
DATABASE_URL=sqlite:///./arbiter.db

# Comma-separated list of directories to scan for projects
PROJECT_ROOTS=/home/user/dev
PROJECT_SCAN_DEPTH=4

# LLM integration
LLM_BASE_URL=https://api.openai.com/v1
LLM_API_KEY=
LLM_MODEL=
LLM_REASONING_EFFORT=none
FILTER_LLM_MODEL=gpt-5.4-nano
AGENT_MAX_STEPS=12

# Safety policy defaults
AUTO_APPROVE_READ_ONLY=true
AUTO_APPROVE_LOW_RISK=false

# Port allocation range
DEFAULT_PORT_SEARCH_RANGE_START=3000
DEFAULT_PORT_SEARCH_RANGE_END=9999

# Live observation refresh interval
OBSERVATION_INTERVAL_SECONDS=3
```

## Important Settings

### `PROJECT_ROOTS` and `PROJECT_SCAN_DEPTH`
A comma-separated list of base directories and a bounded discovery depth from 1 to 8. Arbiter never scans the whole filesystem.

### `LLM_*` variables
Configure `LLM_BASE_URL`, `LLM_API_KEY`, and `LLM_MODEL` for open-ended tool calling. Core and deterministic natural-language operations do not require an LLM.

### API Host
The API host (`ARBITER_HOST`) should remain loopback (`127.0.0.1`). Arbiter
refuses a non-loopback bind unless `ALLOW_REMOTE_ACCESS=true`; that escape hatch
is not a substitute for authentication or an external security boundary.
`ARBITER_TRUSTED_HOSTS` is a comma-separated exact allowlist used to reject Host
header attacks and DNS rebinding. Wildcards are intentionally rejected. Add the
public hostname explicitly when Arbiter sits behind an authenticated reverse
proxy. Legacy
`DEV_AGENT_HOST` and `DEV_AGENT_PORT` aliases remain accepted during migration.

### `ARBITER_STATE_DIRECTORY`

Operational backups are stored outside registered projects under this directory,
with owner-only directory and file permissions. The default is
`$XDG_STATE_HOME/arbiter`, falling back to `~/.local/state/arbiter`. This prevents
backup copies of `.env` and Compose files from entering a project Docker build
context.

# Configuration

The `.env.example` file documents the supported settings for configuring the Local Development Environment Agent.

Copy the example file to `.env` to override the defaults.

```bash
cp .env.example .env
```

## Example `.env`

```bash
# Server bindings
DEV_AGENT_HOST=127.0.0.1
DEV_AGENT_PORT=8765

# Data persistence
DATABASE_URL=sqlite:///./dev_agent.db

# Comma-separated list of directories to scan for projects
PROJECT_ROOTS=/home/user/dev

# LLM integration
LLM_BASE_URL=https://api.openai.com/v1
LLM_API_KEY=
LLM_MODEL=
LLM_REASONING_EFFORT=none
AGENT_MAX_STEPS=12

# Safety policy defaults
AUTO_APPROVE_READ_ONLY=true
AUTO_APPROVE_LOW_RISK=false

# Port allocation range
DEFAULT_PORT_SEARCH_RANGE_START=3000
DEFAULT_PORT_SEARCH_RANGE_END=9999
```

## Important Settings

### `PROJECT_ROOTS`
A comma-separated list of base directories. The discovery process examines each configured root and its immediate child directories only. It does not recursively scan your entire filesystem.

### `LLM_*` variables
Configure `LLM_BASE_URL`, `LLM_API_KEY`, and `LLM_MODEL` for open-ended tool calling. Core and deterministic natural-language operations do not require an LLM.

### API Host
The API host (`DEV_AGENT_HOST`) should remain loopback (`127.0.0.1`) unless you explicitly add an external authentication boundary, as the agent deliberately assumes it is accessed by the local developer.

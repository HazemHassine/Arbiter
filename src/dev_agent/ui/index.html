Resource topology

A fresh typed graph joins registered projects, Compose declarations, Docker runtime state, processes, ports, storage, and build files. Runtime data is observed—not treated as persisted truth.

A small model may convert natural language into a strict filter plan. The plan is validated, then applied deterministically. Failure falls back to the local parser.
